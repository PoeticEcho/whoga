# Telegram 연결 보완 (NAS 3.2.1)

개인 아이디나 사용자명을 직접 입력하지 않습니다. BotFather에서 만든 전용 봇의 토큰을 NAS에 입력하고, 생성된 봇 링크로 들어가 시작을 누른 뒤 연결을 확인합니다. 일회용 연결 명령과 일치하는 개인 대화의 채팅 ID를 자동 저장합니다.

시작 버튼이 보이지 않으면 화면에 표시된 `/start hg_...` 명령을 복사해 해당 봇의 개인 대화에 보낸 뒤 연결 확인을 누릅니다. 코드는 10분 동안 유효하며 NAS가 재시작되면 토큰 확인부터 다시 진행합니다. 페이지 새로고침은 진행 중인 연결을 복원합니다.

단지 목록 조회 오류와 Telegram 상태 조회를 분리했습니다. Telegram 네트워크 요청 중 전체 앱 상태 잠금을 유지하지 않으며, 브라우저는 40초 뒤 응답 지연을 알려줍니다. 토큰 오류·다른 수신기 충돌·DNS·HTTPS 인증서·시간 초과 오류는 각각 안내합니다.

NAS config/output 볼륨을 유지해 3.2.1로 재빌드합니다. Telegram 연결은 NAS 화면에서 진행합니다. 토큰과 개인 채팅 ID는 GitHub에 업로드하지 않습니다. 기존 webhook은 자동으로 삭제하지 않습니다.

검증: 58개 NAS 단위 검사와 브라우저에서 토큰 확인→새로고침 복원→연결→테스트 발송→알림 켜기/끄기→연결 해제 흐름을 검사했습니다. Telegram 응답은 테스트 대역이며 실제 NAS 토큰으로 발송한 검사가 아닙니다. 이번 사용자 NAS의 실패 원인은 실제 오류 문구 확인 전까지 확정하지 않았습니다.
