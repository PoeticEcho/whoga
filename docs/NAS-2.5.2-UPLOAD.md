## 기존 NAS 업데이트

1. 진행 중인 수집·업로드가 끝난 뒤 ZIP의 `nas/`와 `experiments/`를 기존 폴더에 덮어씁니다.
2. 기존 프로젝트 이름, `.env`, 설정·결과 볼륨을 유지하고 Container Manager에서 다시 빌드·시작합니다. `down -v`는 실행하지 않습니다.
3. 화면에서 2.5.2를 확인합니다. 기존 성공 JSON은 결과 볼륨에 유지됩니다.
4. GitHub 설정에서 저장소 `PoeticEcho/whoga`, 브랜치 `map-collector-v2`, 해당 저장소 Contents 읽기·쓰기 권한의 토큰을 저장합니다. 토큰은 NAS 화면에만 입력합니다.
5. 자동 전송을 원하면 ‘전체 수집 성공 후 자동 업로드’를 켭니다. 이미 끝난 수집 결과는 ‘GitHub 업로드’ 버튼으로 전송합니다. 연결 확인만으로 실제 쓰기 성공이 검증되지는 않습니다.

로컬 검사: 기존 단위 검사 40개, 실제 HTML/JS를 여는 Chromium 화면 회귀 검사 5개 통과. 테스트의 업로드 응답은 로컬 모사이며 실제 GitHub 전송 성공을 뜻하지 않습니다. 실제 NAS 업데이트 및 업로드는 설치 후 확인해야 합니다.
