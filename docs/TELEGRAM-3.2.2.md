# Telegram 자동 연결 (NAS 3.2.2)

기본 흐름은 **토큰 확인 → Telegram에서 봇 열기 → 시작 한 번**입니다. NAS 관리 페이지를 열어 두면 약 4초 간격으로 일회용 연결 메시지를 확인하고 채팅 ID를 저장합니다. 별도의 연결 확인 버튼이나 명령 복사가 기본 과정에 필요하지 않습니다. 페이지 새로고침 및 Telegram에서 돌아왔을 때도 유효한 대기를 복원합니다.

Telegram에서는 봇이 사용자와 먼저 대화를 시작할 수 없어 최초 한 번의 시작 동작은 필요합니다. 자동으로 완료할 수 없는 Telegram 클라이언트의 경우 명령과 재확인 버튼을 **자동 연결이 지연될 때** 안에 보관했습니다. 사용자 본인의 일회용 코드가 포함된 개인 대화만 연결합니다. 일반 /start나 무관한 이전 대화를 임의로 선택하지 않습니다.

기존 연결을 다시 설정할 필요는 없습니다. config/output 볼륨을 유지해 재빌드하면 기존 토큰·채팅 ID·알림 설정을 유지합니다. 새 봇으로 재연결하는 경우에도 새 연결이 확인될 때까지 기존 저장 정보를 보존합니다. 새로 연결한 봇의 자동 알림은 테스트 후 사용자가 켭니다.

검증: NAS 단위 검사 및 실제 브라우저에서 자동 연결, 수동 확인 없이 완료, 새로고침 복원, 예외 처리 UI, 알림 켜기/끄기/해제를 검사했습니다. Telegram 서버 응답은 테스트 대역이며 사용자의 실제 NAS에서 수행한 실수집/실메시지 검사가 아닙니다.
