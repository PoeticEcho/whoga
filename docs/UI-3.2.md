# 호가정리 3.2 UI

NAS의 글꼴, 입력칸, 선택 상자, 버튼 크기와 카드 간격을 통일했습니다. 상단 고정 메뉴로 단지 관리, 알림 연결, 수집 설정, 실행 기록을 이동합니다. 단지별 실행 결과는 카드로 나눕니다.

Telegram은 봇 준비 → 내 대화 연결 → 알림 설정의 3단계입니다. 진행 단계에 맞춰 버튼을 활성화하며 요청 중 중복 클릭을 막습니다. 연결 안내와 오류는 Telegram 영역 안에서 표시합니다. 연결 또는 해제 후 이전 연결 링크를 숨깁니다. 실제 Telegram 연결 프로토콜은 변경하지 않습니다.

공개 앱은 단지 선택, 기준/비교 시점, 주요 메뉴의 터치 영역을 넓혔습니다. 선택 자료의 단지명, 매물 카드 수, 중개 등록 수, 수집 시각을 표시합니다. 매물 텍스트는 내부 스크롤로 읽고 하단 전체복사를 사용할 수 있습니다.

데스크톱 및 390px 모바일에서 메뉴 이동, 가로 넘침, Telegram 단계별 버튼 상태, 자료 표시와 JavaScript 오류를 검사했습니다. NAS 기능 사용에는 기존 config/output 볼륨을 유지한 3.2 재빌드가 필요합니다. 공개 앱은 배포 후 새로고침하면 됩니다.
