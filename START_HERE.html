whoga · W 호가 · GitHub Pages 배포본 v1.0.0

웹페이지부터 열고,
매일 알림을 연결하세요.

별도 PHP 서버나 데이터베이스 없이 사용할 수 있는 배포 패키지입니다. 이 파일은 설치 안내이며 호가 대시보드는 index.html입니다.

포함된 4개 자료는 첨부 기준 자료입니다. 실제 네이버 자동 수집과 텔레그램 발송은 첫 실행에서 확인해야 합니다.

1. GitHub Pages 배포

  1. 빈 공개 저장소를 만들고 ZIP을 풉니다.

    GitHub Free에서 Pages를 사용할 때는 Public 저장소가 필요합니다.

  2. ZIP 내부의 파일·폴더 전체를 main 브랜치에 업로드합니다.

    .github/workflows/daily_briefing.yml도 포함해야 합니다. ZIP 자체를 올리면 실행되지 않습니다.

  3. Settings → Pages → Source → GitHub Actions를 선택합니다.
  4. Actions → whoga · W 호가 & Pages → Run workflow를 실행합니다.

    첫 실행은 collect, notify를 모두 해제합니다.

  5. 배포 작업에 표시된 URL로 접속합니다.

2. 수집·알림 연결

  1. Run workflow에서 collect만 선택해 실제 수집 성공 여부를 확인합니다.

    수집 실패 시 기존 자료는 보존됩니다.

  2. 텔레그램 봇을 만들고 수신 계정에서 봇과 대화를 시작합니다.
  3. Settings → Secrets and variables → Actions의 Secrets에 두 값을 등록합니다.
    이름값
    TELEGRAM_BOT_TOKEN봇 토큰
    TELEGRAM_CHAT_ID수신 대화 ID
  4. Run workflow에서 notify만 선택해 현재 자료의 알림이 도착하는지 확인합니다.
  5. Variables에 ENABLE_DAILY = true와 ENABLE_TELEGRAM = true를 등록합니다.

    매일 한국시간 오전 8:13 전후 실행하며 GitHub 대기열에 따라 지연될 수 있습니다. 중단하려면 false로 바꿉니다.

3. 자동 수집이 안 된다면

네이버 페이지 변경이나 접근 제한으로 수집이 중단될 수 있습니다. 대시보드의 수동 자료에서 JSON 또는 네이버 복사 원문을 가져올 수 있습니다.

수동으로 가져온 자료는 해당 브라우저에만 저장됩니다. 공유 자료에 반영하는 명령과 전체 설치 방법은 README.md에 있습니다.

컴퓨터에서 미리 보려면 python scripts/build_site.py 실행 후 python -m http.server 8000 --directory _site로 서버를 열고 http://localhost:8000에 접속하세요.

호가는 실거래가와 다릅니다. 미관측은 거래 완료를 뜻하지 않습니다. 같은 조건 묶음은 동일 호수 여부를 확정하지 않습니다.
